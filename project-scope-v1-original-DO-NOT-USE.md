# AI-Powered Invoice Creation and Management System

## Problem

We have to write out invoices manually for each client and job. We don't have a system for automatically storing invoice/estimates and need to send out invoice/estimate manally to emails/phone numbers. We need to download the files and convert them to pdf before sending them and we need to remind ourselves of who owes what or what projects we've done for clients. Also we need to remind ourselves to check and input payments that have been made or check which are still missing

## Solution

Build an invoice/estimate management system that uses AI to automaitcally refine, create, and store emails/invoices, clients, project details, and price. Should also turn invocies to pdfs, email/sms them to the client, and store to a database.

## Features

- Ai refine prompts
- Store clients to database
- Store invoices to database
- Store different projects and their details
- Search/lookup for clients, invoices, projects
- Create pdfs
- Email pdfs
- SMS pdfs
- Accessible over web
- Client management (admin only)
- Dashboard to view and manage all invoices/estimates/clients
